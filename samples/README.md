# Sample data

> **Illustrative company, synthetic data.** Northlake, Inc. is not a real business. Every figure
> here is generated by a seeded simulator. No real company, no real people, no scraped data.

The first ~1,000 rows of every table the generator produces, as CSV, so the dataset can be read
on GitHub without cloning the repository or running anything.

These are **committed build output** — the only such artifact here. Everything else the build
produces (Parquet, workbooks, PDFs, PNGs) is gitignored, because it is large, binary, or both.
These are small, text, and diff cleanly, and this project has an audience that reads the
repository rather than running it.

Regenerate with:

```
python -m bellwether.build
```

The generator is deterministic, so an unchanged generator rewrites these byte for byte and the
working tree stays clean. If a diff appears here, the data genuinely changed — which is the
point. A change to a driver shows up as a change to rows a reviewer can see, in the same commit
as the code that caused it.

The full dataset lands in `data/parquet/` and is gitignored. Parquet preserves the dtypes these
CSVs flatten, including money stored as integer minor units.
